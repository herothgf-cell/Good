# Guardian Learning v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox syntax for tracking.

**Goal:** Replace the default guardian learning experience with meaningful English and math practice while preserving coupons and keeping children unexposed.

**Architecture:** New pure content/state modules next to legacy learning, a separate guardian controller, and an authenticated adult-only voice coach. Existing family CAS/receipts remain the persistence boundary; no schema migration is needed.

**Tech Stack:** TypeScript 5.8.3, dependency-free browser DOM, Supabase Edge Functions, Node test runner, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-01-learning-v2-design.md`
**Interfaces:** `docs/technical/LEARNING_V2_CONTRACT.md`

## Global Constraints

- EBS deferred; no child v2 exposure or reward changes.
- Preserve legacy learning, balances, coupons, auth and production publication settings.
- Reviewed deterministic math/content; no pronunciation-score or diagnosis claims.
- Server API keys only; actual conversation adult/admin only, missing configuration honest, no stored transcripts/audio.
- Worker file ownership is exclusive; root owns integration and release. User has authorized execution; no repeated approval gate.

## Review Focus

- Foreign role/family and stale settings cannot mutate new lab data or start paid requests.
- Month/hour boundaries and regrouping constraints always match question/visual/solution.
- Hidden target labels/alt text cannot leak recall answers.
- Network/save retries cannot double progress or reward; paid turns cannot auto-repeat.
- Leaving, changing account or hiding tab releases microphone/audio and ignores late callbacks.
