# 보호자 학습 테스트와 선택적 아이 공개

## 승인된 목표
기존 칭찬 쿠폰 앱에 영어·수학 학습을 추가한다. 사용자는 2026-10-31 개발 진행을 요청했고, 개발·검증 중에는 보호자 모드의 별도 메뉴로 테스트하며 추후 보호자가 실제 아이 노출로 이어가는 운영을 요청했다. 기존 별·상점·뽑기 공개 설정·시간 쿠폰 흐름은 보존한다.

## 범위와 접근
첫 버전은 검수한 짧은 영어 듣기/선택/선택적 따라 말하기와 수학 조작 그림/선택 활동이다. 실시간 자유회화, 마이크, 외부 AI 호출, 검사 점수 진단은 이번 범위에 넣지 않는다. 영어 읽어주기는 기기 음성 합성이 가능할 때만 사용하며 텍스트 도움과 보호자 읽어주기 대안을 제공한다.

보호자 관리자는 `학습 테스트` 전용 화면에서 여섯 활동을 미리 해보고 공개할 활동, 하루 활동 한도, 보호자 확인 후 지급할 별을 설정한다. 기본 상태는 미공개다. 선택한 활동을 끝까지 테스트한 뒤 별도의 확인으로 `아이에게 공개`한다. 공개 취소는 즉시 가능하다. 설정을 저장하는 것과 공개하는 것은 별개이며 공개된 설정은 복사본으로 보존한다.

영어 활동 세 개(색깔, 동물, 물건 요청)와 수학 활동 세 개(10 만들기, 자리값, 짧은 덧셈·뺄셈 이야기)를 각 다섯 문항으로 준비한다. 정답과 그림 수량은 검수된 데이터가 결정한다. 오답 뒤 다시 선택하거나 힌트를 쓸 수 있으며 속도 점수·벌점은 없다. 따라 말하기는 선택이며 음성 인식으로 채점하지 않는다.

## 권한과 기록
- admin: 테스트, 초안 설정, 공개/중지, 아이 완료 기록 확인과 칭찬.
- child: 현재 공개된 활동만 실행·완료 가능. 테스트·설정·공개·자기 별 지급은 서버에서도 거절한다.
- giver: 기존 칭찬 권한만 유지하고 학습 관리 권한은 추가하지 않는다.
- 보호자 테스트 기록은 아이 학습 기록·일일 횟수·별·쿠폰에 영향을 주지 않는다.
- 아이 완료 기록은 자동 별 지급 없이 보호자 확인 대기다. 보호자가 한 번 확인해 기존 별 원장·칭찬 편지에 연결한다.
- 기기별 로그인과 무관하게 가족 단위로 하루 횟수와 같은 실행 ID의 중복 처리를 검증한다.
- 공개 중지/변경 뒤 오래된 아이 화면에서 보내는 완료는 거절한다. 새 상태를 받으면 진행 중 화면과 음성을 정리한다.
- 기존 가족은 학습 필드가 없어도 그대로 읽히며 조회만으로 원본 상태를 쓰지 않는다.

## 저장 결정
이번 버전은 음성·대화·heartbeat 없이 작은 완료 요약만 저장하므로 선택적 `State.learning` 필드를 사용한다. 보호자 테스트 최근 30개, 아이 완료 최근 60개를 유지하고 기존 칭찬/원장은 보존한다. 대량 장기 학습 로그나 다자녀는 별도 테이블로 확장할 후속 범위다. 코드 배포와 아이에게 공개하는 설정은 분리한다. 이번 배포에서 실제 가족의 공개 상태를 켜지 않는다.

## 완료 기준
기존 데이터와 거래 회귀 검사가 통과하고, 기본 아이 비노출·서버 권한·테스트 무보상·테스트 후 공개·설정 분리·중지·중복 보상·기기 공통 한도·iPad 크기 화면을 검증한다. 기존 웹 주소에서 보호자가 테스트할 수 있게 배포하되 미공개 기본값을 유지한다.
