# 통합 대화와 칭찬 편지 관리

사용자 요청: 말풍선 대화에서 글과 AI 음성을 함께 제공. 행동 삭제/순서 수정. 아이 홈은 읽지 않은 편지만 크게 표시. 읽은 편지는 별도 보관함. 보호자가 실제 행동을 칭찬하는 날짜를 선택.

기준: 운영 main f4a50cc(v0.9); 미배포 v0.10을 먼저 통합. 첨부 대화 캡처는 좌우 말풍선 레이아웃 참고만 사용하고 가족의 대화 내용은 코드/예시에 복사하지 않는다.

결정: 별도 음성 통화 화면 대신 기존 대화 화면에서 AI(왼쪽), 보호자(오른쪽)를 표시. 전송 중/실패 상태를 보존. AI 생성 음성을 같은 말풍선에서 다시 듣기. 기존 v0.10의 순차 파닉스/AI 읽기는 유지. 학습은 보호자 테스트에만 노출.

행동: 위/아래 이동, 삭제 전 확인, 서버 관리자 권한/버전 검사. 삭제는 보이는 목록에서 제거하되 내부 삭제 표식과 과거 칭찬/별 원장은 보존. 모든 화면은 저장된 순서를 사용(홈은 대표 행동 우선).

편지: 읽음 버튼으로만 읽음 처리. 새 편지함에는 미확인·유효 편지만, 보관함에는 읽음·유효 편지만. 홈은 새 편지가 없으면 간단한 안내와 보관함 링크만. 발송순으로 새 편지를 찾고 칭찬일자가 과거여도 새로 도착한 편지로 표시한다.

날짜: praiseDate는 실제 행동 날짜, createdAt은 변경 불가한 발송 시각. 생략 시 한국 날짜 오늘. 실제 달력 날짜 검증 및 미래 날짜 거부. 행동 일일 횟수는 칭찬일자 기준. 원장/정정/잔액은 실제 지급 시각 유지.

비범위: 아동 AI 공개, EBS, 음성 발음 채점, 기존 데이터 삭제, 스크린샷 가족 대화 저장.
