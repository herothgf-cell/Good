# 보호자 실시간 음성 회화

사용자가 승인한 방향: 기존 앱에서 AI 생성 음성으로 자연스럽게 대화한다. 시작 후 매번 녹음 버튼을 누르지 않는다. 기존 쿠폰·수학·단어·읽기와 아이 미공개 상태를 유지한다.

## 선택한 방식
기기 TTS는 사용자가 원하는 목소리가 아니므로 새 기능에서 사용하지 않는다. 파일 녹음→전사→텍스트→TTS 방식은 이전 비교 도구로 보존한다. 새 기능은 OpenAI Realtime WebRTC unified call 방식: 브라우저 SDP를 인증된 Edge 서버에 보내며 서버만 실제 API 키를 사용한다. AI 오디오는 WebRTC 원격 오디오 트랙으로 재생한다.

## 범위
- 보호자 cloud 계정만, 명시적 시작 클릭 후 마이크 권한 요청. AI임을 화면과 첫 인사에서 알린다.
- 기본 모델 gpt-realtime-2.1-mini, 기본 음성 marin, 선택 cedar. 0.9배 속도. 기존 OPENAI_API_KEY / LEARNING_COACH_ENABLED=guardian 재사용. 선택적 LEARNING_REALTIME_MODEL 서버 설정.
- AI가 인사한 뒤 자동 차례 전환. semantic VAD low / create_response=false / interrupt_response=false. 짧은 yes/no를 버리는 길이 필터는 사용하지 않는다. AI 재생 중 마이크 트랙 disabled, 재생 종료 후 700ms 여유. 한 번에 응답 한 개.
- 영어 중심, 한국어 뜻 도움과 짧은 표현 모델. 놀이·가게·만들기 주제, 1~2개 짧은 문장과 질문 최대 하나. 진단/발음 점수/자동 별 지급 없음.
- 현재 AI 발화의 자막 표시 선택. 음성·자막·SDP는 DB/로컬 저장소/로그에 저장하지 않는다. API 공급자 보관 정책은 별도이며 ZDR 보장 아님.
- 종료/일시정지/탭 숨김/화면 이동/권한 변경은 모든 트랙·peer·타이머를 정리. 늦은 권한/서버 응답도 다시 마이크를 켜지 않는다. 자동 재연결이나 유료 요청 재전송 없음.

## 서버 통제
새 learning-realtime Edge 함수는 Auth user 검증과 family_members admin 조회를 수행한다. 기존 family_commit CAS를 이용해 JSON 상태의 별도 learningRealtime 메타데이터만 저장한다. 기존 서버/DB 스키마는 수정하지 않는다. 하루 6회 시작 예약(한국 날짜), 가족 동시 연결 1개, UUID 중복은 추가 세션 생성 금지. SDP/키는 영수증에 저장하지 않는다. call ID는 서버가 받은 값을 기록하고 클라이언트 임의 call ID는 받지 않는다.

테스트 한 세션은 5분, 40회 응답까지. 20초마다 heartbeat로 권한/기한을 재확인한다. 서버는 만료·중지된 call을 hangup한다. 중지와 세션 생성이 경쟁하면 생성된 call을 즉시 종료한다. **독립적인 서버 감시 작업은 이번 범위가 아니다.** 브라우저가 강제 종료되고 후속 요청도 없으면 서버의 5분 시각에 hangup하는 보장은 없다. 브라우저 peer 종료와 다음 서버 접근 시 만료 회수가 기본 방어이다. 아이 공개/다중 가정 서비스 이전에는 독립 reaper가 필요하다.

## 검증
권한/크기/원본 불변/동시 예약/소유자/유료 중복/중지 경쟁/음성 autoplay 실패/짧은 발화/음성 재생 완료와 생성 완료 차이/late callback/숨김/네트워크 실패를 테스트한다. 실제 API 키를 읽거나 실제 가족을 사칭해 검사하지 않는다. 실제 기기의 음질과 실시간 네트워크는 보호자가 확인해야 한다.
