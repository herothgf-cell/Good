# 행동 관리와 칭찬 편지 정리

사용자 요청: 행동 목록 삭제/순서 수정, 아이 홈에는 안 읽은 편지만 크게 표시, 읽은 편지는 별도 보관함, 보낼 때 칭찬한 날짜 선택.

- 기존 TypeScript 웹앱과 가족 상태/원장 명령 처리에 통합한다. 학습과 쿠폰 공개 상태는 변경하지 않는다.
- 행동 삭제는 목록에서 제외하는 소프트 삭제다. 과거 칭찬/별/쿠폰은 그대로 유지한다. 오래된 편집/지급으로 삭제된 행동을 복원하지 못한다.
- 위/아래 버튼으로 목록 전체(숨긴 행동 포함)의 순서를 즉시 저장한다. 목록 버전과 정확한 ID 집합을 검사하여 동시 변경을 덮어쓰지 않는다. 홈은 기존 우선 표시 설정을 유지하되 각 그룹 안에서 저장 순서를 따른다.
- 아이 홈의 큰 편지는 가장 최근 도착한 안 읽은 편지뿐이다. 전부 읽으면 큰 본문을 없애고 간결한 빈 상태를 표시한다. 새 편지함에는 안 읽은 편지만, 보관함에는 읽은 편지만 표시한다. 열어보기만으로 읽음 처리하지 않고 `읽었어요`를 누른 뒤 이동한다.
- praiseDate(YYYY-MM-DD)는 행동한 날이다. 기본 한국 날짜 오늘; 오늘/어제 바로가기와 달력 입력. 실제 존재하는 과거/오늘 날짜만 허용한다. createdAt과 원장은 실제 전송 시각을 유지한다.
- 행동별 하루 횟수와 같은 내용 중복 경고는 praiseDate 기준. 이전 기록은 createdAt의 한국 날짜를 대체값으로 사용한다. 전송/원장 시간순은 유지한다.
- 일반 칭찬과 행동 바로 칭찬 모두 날짜를 선택한다. 오늘 횟수가 끝나도 지난 날짜 칭찬을 시작할 수 있다. 날짜별 한도는 서버가 최종 확인한다.
- 사용자 추가 지시: 실제 운영에 미반영된 v0.10 통합영어를 포함하여 배포한다. 채팅 한 화면의 글/AI 음성, 파닉스 읽기/쓰기 통합을 유지하고 보호자 테스트 전용을 보존한다. 원본 PDF는 공개 저장소에 업로드하지 않는다.
