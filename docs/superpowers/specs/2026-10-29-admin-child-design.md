# v0.5 보호자 관리 · 연준이 편지함

사용자가 승인한 모바일 검토안과 추가 요청(칭찬 편지를 더 잘 보이게, 글씨 확대)을 구현한다.

## 목표
- 보호자: 홈/별 주기/쿠폰/보상/설정. 실제 구매·뽑기는 서버에서도 금지. 별·선물 직접 지급과 승인 유지.
- 아이: 홈/별 받기/상점/뽑기/내 쿠폰. 홈 최상단에 칭찬 편지, 새 편지 개수, 보낸 사람, 받은 별. 전체 편지함과 읽음 처리.
- 기본 본문 16px, 편지 본문 18~20px, 버튼 최소 44px. 360/390/430/768px 검증.
- 보호자가 칭찬 행동(아이콘/이름/설명/1~3별/일일 제한/공개/우선표시)을 설정. 자동 지급 없이 어른이 확인해 지급.
- 쿠폰 상태별 필터/묶음/개별 처리, 보상 검색/상태 필터, 아이콘 분류와 최근 사용, 무차감 시험 뽑기.
- 직접 지급 별 정정과 미사용 선물 회수는 사유와 원본 보존. 음수 잔액·중복 회수 금지.
- 아이콘 선택 팝업 Escape/닫기/초점 복귀, 미저장 편집 확인.

## 설계 결정
기존 TypeScript/정적 웹앱/Supabase family JSON/CAS 원장을 유지. 새 필드는 선택적이라 과거 기록을 이관/초기화하지 않는다. 편지 읽음은 가족의 아이 프로필에 저장해 여러 아이 기기에서 공유한다. 프로필당 아이 1명 범위 유지. 브라우저 알림/푸시/PC 전원 제어는 구현하지 않는다.

선택지: 기존 메뉴 일부 숨김(관리 동선 해결 부족) 대신 역할별 홈/탭을 분리한다. 인증 세션을 실제로 바꾸는 '아이 보기' 대신 쓰기 불가능한 미리보기를 둔다.
