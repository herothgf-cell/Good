# 영어 회화·파닉스 통합 v0.10

## 달라진 화면

**보호자 → 학습 테스트**의 영어 활동은 다음 두 개다.

1. **영어 회화 · 음성 + 글**: 기존 글·녹음 입력 대화를 유지하고 같은 답변을 AI 생성 음성으로 읽는다. 별도의 WebRTC 음성 전용 패널과 고정 시나리오 퀴즈는 현재 진입 경로에서 노출하지 않는다. 대화 내용, 한국어 도움, 모델 문장은 같은 창에 남는다. 소리가 실패해도 글은 남으며 **AI 답변 다시 듣기**로 재생한다. 짧은 녹음 버튼은 기존 방식대로 유지한다.
2. **파닉스 · 단어·읽기·쓰기**: 서울시교육청 자료의 22개 단원 + 별도 ai/ay 보충. **단원 선택**에서 현재 배우는 범위로 바로 이동할 수 있다. 매번 무작위 낱말을 고르는 대신 `듣고 뜻 알기 → 직접 읽기 → 따라 쓰고 철자 완성 → 뜻에서 떠올리기`를 단어 순서대로 진행하고 마지막에 문장·복습을 한다.

보호자 테스트만 제공하며 아이 메뉴·공개 설정·별·쿠폰·수학은 변경하지 않는다. 과거 단어/읽기 결과는 learningLab 기록에 남고 새 진도와 섞어 실력 점수로 계산하지 않는다. EBS는 포함하지 않는다.

## AI 소리와 쓰기

- 기기 영어 음성 설치나 부모의 읽어주기를 요구하지 않는다. 기존 서버의 `OPENAI_API_KEY`와 `LEARNING_COACH_ENABLED=guardian`을 재사용한다.
- 파닉스에서 자동 읽기를 켜면 듣기·문장 단계에 진입할 때 AI 음성을 요청한다. 브라우저가 재생을 막으면 **AI 다시 듣기**를 누른다. 마이크 권한은 읽어주기에 필요 없다.
- 통신이 안 되거나 크레딧·모델 권한 문제가 있으면 안내와 글을 표시한다. 가짜 읽기 성공으로 기록하지 않는다. 자동 읽기는 끌 수 있다.
- 손가락·펜으로 연한 글자를 따라 쓰고, 아래 입력칸/글자 타일로 낱말 철자를 완성한다. **손글씨 모양이나 발음은 자동 채점하지 않는다.** 틀린 철자는 같은 단계에서 다시 확인한다. 도움을 쓰거나 다시 연습으로 넘긴 결과는 혼자 푼 기록과 구분한다.
- 개별 음소를 합치는 표기는 PDF에서 가져와 화면으로 제공한다. 현재 AI 음성은 전체 낱말·문장의 시범이지 독립 음소 정확성 검증을 마친 음원이 아니다. 원문 문장에는 선행하지 않은 낱말도 있어 함께 듣고 읽도록 표시한다.

## 저장과 다시 시작

완료한 단계마다 `learningEnglish`에 선택 단원·커서·시도 차수·결과(스스로/도움/다시 연습)만 저장한다. 끝내지 않은 입력 글과 손글씨 획은 저장하지 않으며, 음성·대화 원문도 가족 상태에 넣지 않는다. `이 단원 처음부터 다시 연습`은 해당 단원의 **최신 시도 기록을 초기화**하고 시도 차수를 올린다. 전체 평생 학습 이력 기능은 아니다.

저장 실패 시 **같은 기록 다시 저장**은 같은 요청 번호를 사용한다. 다른 기기에서 진도가 먼저 이동하면 덮어쓰지 않고 다시 불러오도록 안내한다. 체험 모드는 현재 페이지의 메모리만 사용하므로 실제 계정의 영구 저장·AI 호출과 다르다.

## 서버 구조 및 배포

신규 `learning-english` Edge Function을 JWT 검증을 켜 배포한다. 기존 family-action, learning-coach 및 learning-realtime 함수는 이 변경으로 덮어쓰지 않는다. 새 SQL 마이그레이션 없이 기존 service_role 전용 `family_commit`의 revision/CAS와 요청 영수증을 재사용한다. 함수 안에서도 Auth 사용자와 가족의 admin 역할을 다시 확인한다.

사용자 원문 대신 SHA-256 digest를 거래 payload에 남긴다. AI 읽어주기는 가족당 한국 날짜 하루 120회 예약, 동시에 2회, 요청 본문 6KB, text 800자, PCM 2.4MB, 45초 타임아웃으로 제한한다. 예약된 실패는 횟수에 포함된다. 같은 요청 ID를 재전송해도 유료 음성을 중복 생성하지 않는다. 음성 슬롯은 종료 때 반환하고 누락 시 60초 뒤 정리 대상이 된다.

최신 공식 Speech API 종료 안내에 따라 신규 `/audio/speech` 의존성 대신 **서버의 짧은 Realtime WebSocket 읽어주기**를 사용한다. `npm:ws@8.22.1`, 기본 모델 `gpt-realtime-2.1-mini`, 선택 환경변수 `LEARNING_READ_MODEL`. 출력 음성의 전사문이 요청한 글과 일치하는지 확인하고 불일치면 반환하지 않는다. 이 검사는 발음 정확도 점수가 아니다. 생성이 끝나면 연결을 종료한다. API 키는 브라우저로 보내지 않는다.

클라이언트는 WAV/Blob URL을 현재 화면의 메모리에 최대 16개 캐시한다. 같은 단계/답변 재생은 캐시를 사용하며 화면 이탈·숨김·계정 변경 때 폐기한다. 캐시는 서버나 영구 저장소에 남지 않는다. 공급자의 데이터 처리·보관 정책까지 ‘보관 없음’이라고 보장하지 않는다. 성인 보호자 테스트만 허용하며 아이 음성 공개는 별도 조건 검토가 필요하다.
