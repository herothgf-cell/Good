# 보호자 실시간 음성 회화 — v0.9.0

기존 칭찬 쿠폰 앱의 **보호자 → 학습 테스트 → AI와 음성으로 대화하기**에서 사용합니다. 새 화면은 아이에게 공개되지 않습니다. 실제 사람이 아닌 AI임을 안내하고, 성인 보호자의 목소리로만 시험합니다.

## 사용 순서

1. 가족 공유의 보호자로 로그인합니다. 체험 모드는 실제 AI나 마이크를 사용하지 않습니다.
2. `AI와 음성으로 대화하기`를 열고 **음성 대화 시작**을 누릅니다.
3. 브라우저 마이크 권한을 허용합니다. AI가 먼저 인사합니다.
4. `당신의 이야기를 듣고 있어요`가 표시되면 말합니다. 매번 녹음 시작/전송 버튼을 누르지 않습니다.
5. AI가 말할 때는 마이크를 닫고, 실제 오디오 재생이 끝난 뒤 다시 엽니다. 짧은 yes/no도 길이 때문에 제외하지 않습니다.
6. `대화 종료`, 잠깐 쉬기, 다른 화면 이동 또는 탭 숨김으로 마이크와 연결을 닫습니다.

기본 자막은 숨김이며 **영어 자막 보기**에서 현재 AI 발화를 확인할 수 있습니다. 한국어로 말해도 간단한 영어 표현으로 연결하도록 지시했습니다. 실제 발화가 항상 지시를 지킨다는 보장은 없습니다. 발음 점수·학습 완료·별 지급은 자동으로 만들지 않습니다.

기본 목소리는 **Marin**, 대안은 **Cedar**입니다. 연결 전에 선택합니다. 이는 기기 TTS가 아니라 OpenAI Realtime이 생성하여 WebRTC 오디오 트랙으로 전달하는 목소리입니다. 영어 단어·읽기 활동의 기존 로컬 음성 기능은 바꾸지 않았습니다.

## 기존 설정 재사용

이미 등록한 `OPENAI_API_KEY`와 `LEARNING_COACH_ENABLED=guardian`을 사용합니다. 새 키 발급이나 새로운 결제 서비스 가입은 필요하지 않습니다. Realtime도 API 사용량에 따라 비용이 발생하며, 해당 API 프로젝트에 모델 사용 권한과 유효한 크레딧이 있어야 합니다.

선택 설정 `LEARNING_REALTIME_MODEL`의 기본값은 `gpt-realtime-2.1-mini`입니다. 서버에서만 바꿀 수 있습니다. `연결 상태 확인`은 구성값과 보호자 접근 여부를 확인하며, 실제 음성 연결까지 보장하는 API 호출 시험은 아닙니다.

## 화면과 오류

- 마이크가 차단되면 브라우저의 사이트 마이크 권한을 허용한 뒤 다시 시작합니다.
- `소리 켜기`가 나오면 눌러 브라우저 재생을 허용합니다. 소리가 막혔다고 텍스트만 성공한 것처럼 진행하지 않습니다.
- API 모델 권한·키·한도 문제는 짧은 오류로 표시합니다. 공급자의 원본 오류, 키 또는 음성 내용은 표시하지 않습니다.
- 연결/응답 지연이나 네트워크 실패 시 자동으로 유료 세션을 다시 만들지 않습니다.
- 종료 요청이 서버에 전달되지 않으면 기기 마이크·peer는 즉시 닫고, 서버 종료를 확인하지 못했다는 안내를 표시합니다.
- 이전 녹음·글자 대화와 고정 문장 연습은 하단의 **비교용** 접힘 영역에 보존했습니다. 동시에 두 음성 기능을 실행하지 않습니다.

## 제한과 데이터 처리

브라우저 테스트는 한 번에 최대 **5분 / AI 응답 40회**, 90초 무대화면 종료입니다. 서버는 한국 날짜로 **가족당 하루 6회 연결 시작**과 **동시 연결 1개**를 원자적으로 제한합니다. API 생성 전에 횟수를 예약하므로 실패한 시작도 횟수에 포함될 수 있습니다.

20초마다 서버에 권한과 만료 여부를 확인합니다. 종료·만료 또는 오래된 연결은 OpenAI hangup으로 정리합니다. **독립적인 서버 타이머/정리 작업은 이번 보호자 시험판에 없습니다.** 브라우저 강제 종료, 네트워크 단절 후 추가 요청이 전혀 없으면 서버가 정확히 5분 시점에 hangup한다고 보장하지 않습니다. 다음 서버 접속 시 오래된 연결을 회수합니다. 40회 응답 상한도 브라우저 제어입니다. 아이 공개나 다중 가족 상용 배포 전에는 별도의 서버 감시·강제 종료가 필요합니다.

앱은 음성 파일·SDP·대화 전문을 가족 DB, 브라우저 저장소, 애플리케이션 로그에 저장하지 않습니다. 자막은 현재 화면 메모리에만 보관하고 이탈 시 지웁니다. 가족 DB에는 연결 ID, 소유자, 시작/만료 시각, 상태, 횟수 등 운영 메타데이터만 남습니다. API 공급자의 처리·보관 정책까지 무보관이라고 보장하지 않으며 ZDR 승인을 대체하지 않습니다.

## 구현 및 배포

- 별도 `learning-realtime` Edge 함수. 기존 `family-action` / `learning-coach` 함수는 재배포하지 않아도 됩니다.
- `verify_jwt: true` 유지; 함수 안에서도 Auth 조회와 실제 가족 admin 권한을 확인합니다.
- 표준 API 키는 서버에만 둡니다. 서버가 SDP를 교환하는 unified call 방식이므로 브라우저에 API 키나 임시 키도 전달하지 않습니다.
- `family_commit`의 기존 CAS와 영수증을 재사용하며 스키마/권한 마이그레이션은 없습니다. `learningRealtime` 운영 상태만 추가합니다. 별·쿠폰·기존 아이 학습 설정은 변경하지 않습니다.
- 독립 재시도와 동시 요청은 동일한 연결 번호로 두 번 API를 생성하지 않습니다. 종료와 생성이 경합하면 늦은 call을 활성화하지 않고 정리합니다.
- AI 응답 생성 완료(`response.done`)와 오디오 재생 종료(`output_audio_buffer.stopped`)를 구분합니다. 후자에서 700ms 뒤에만 마이크를 다시 엽니다.
- 오디오 요소는 앱 루트 밖에 두어 화면 갱신에 끊기지 않게 합니다. 자막·타이머만 바뀔 때는 해당 텍스트만 갱신하고 키보드 포커스를 보존합니다.

배포 파일: `supabase/deploy/good-learning-realtime.ts`, `supabase/deploy/deno.json`, `supabase/functions/learning-realtime/index.ts`, `_server/config.js`, `_server/realtime.js`, `_server/realtime-store.js` 및 해당 타입 선언. 상대 경로를 유지하여 함께 업로드합니다.

## 검증 범위

자동 검사와 브라우저 테스트는 서버 저장·미디어·WebRTC·공급자 경계를 테스트 대역으로 교체합니다. 실제 API 키를 조회하거나 실제 가족을 사칭해 유료 통화를 만들지 않았습니다. **실제 iPad Safari의 마이크/스피커, 실제 AI 목소리·응답 지연·계정 모델 권한은 보호자의 실제 연결 시험이 남아 있습니다.** 화면 크기 검사나 자동 검사 통과를 실물 음질 검증으로 해석하지 않습니다.
