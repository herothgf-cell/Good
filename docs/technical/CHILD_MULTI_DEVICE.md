# 연준이 단일 프로필 · 여러 기기 (v0.4)

모든 아이 기기가 동일한 `families.state`의 별, 쿠폰, 칭찬 및 뽑기 기록을 사용합니다. 로그인은 기기별 익명 Supabase Auth 세션으로 유지하며, 연준이의 이메일은 필요하지 않습니다. **프로필은 하나의 가족 공유 기록이며, 별도 어린이 인증 계정으로 통합하는 방식이 아닙니다.** 기기별 인증 계정을 유지해야 독립적인 세션 해제가 가능합니다.

## 새 기기 연결
보호자 로그인 → 우리 가족 → 연준이 프로필 → 연준이 기기 추가 → 아이 권한 일회용 코드 발급. 새 기기의 아이 기기 연결에서 기기 이름(예: 집 PC, 태블릿)과 코드를 입력합니다. 각 코드는 1회용이고 48시간 후 만료됩니다. 두 번째 기기를 추가할 때는 새 코드를 발급합니다. 새 가족 만들기를 누르지 않습니다.

## 기기 관리
우리 가족에서 연준이 프로필 아래 등록된 기기를 확인합니다. 보호자는 기기의 표시명을 변경하거나 기기 연결 해제를 수행합니다. 기기를 해제해도 연준이의 공통 별/보상/칭찬 기록은 삭제되지 않습니다. 인증 세션은 기기마다 별개이며 기존 연결 기기에 영향을 주지 않습니다.

## 데이터 보존 및 제한
기존 13개 별 및 원장 유지. 가족당 아이 1명인 MVP이며, 나중에 다자녀별 독립 프로필은 별도 데이터 모델이 필요합니다. 연결 해제는 `family_members` 접근 권한을 제거하며 아이 기기의 인증 자격증명 자체를 삭제하는 것은 아닙니다. 기기 이름은 부모가 구분하는 표시명으로만 사용합니다. 기기 종류를 자동으로 증명하는 정보가 아닙니다.
