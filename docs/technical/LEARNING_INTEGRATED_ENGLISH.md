# 통합 영어 v0.10 — 기능 설계 (v0.11에 통합)

## 변경 범위
기존 칭찬 쿠폰 앱의 **보호자 → 학습 테스트**입니다. 아이 공개·보상·수학 동작은 변경하지 않습니다. EBS는 제외합니다. 별도의 실시간 통화 화면을 주 화면으로 노출하지 않으며, 이전 녹음/텍스트 채팅을 주 화면으로 복원했습니다. 예전 실시간 모듈과 서버는 삭제하지 않아 이전 사용 기록/배포와 충돌하지 않습니다.

## AI 영어 회화: 같은 대화의 글과 목소리
연결 확인 후 문장을 쓰거나 마이크로 녹음하여 보내면 같은 영어 응답·모델 표현을 글로 보여 주고 AI가 생성한 WAV 음성으로 재생합니다. 한국어 도움말은 글로 표시하며 영어 본문과 모델 표현을 읽습니다. 기기 `speechSynthesis`나 설치된 영어 목소리는 사용하지 않습니다.

각 답변의 **이 답변 다시 듣기**는 메모리의 같은 음성을 재생합니다. 다시 듣기로 API를 재호출하지 않습니다. 브라우저의 자동 재생이 차단되면 **소리 재생** 버튼을 보여 줍니다. **음성만 멈추기**는 대화를 보존하고 재생만 멈춥니다. **새 대화**/화면 이탈/탭 숨김은 대화·오디오를 지웁니다. 마이크 녹음은 기존 15초 이내 방식이며, 자동 연속 통화 방식은 아닙니다.

음성 생성이 실패해도 텍스트 답변은 보존하고 실패를 명시합니다. 정상 생성됐다고 가장하거나 부모의 읽어주기로 바꾸지 않습니다. 재생 음성은 AI 생성임을 화면에 표시합니다.

## 파닉스 · 듣고 읽고 쓰기
`뜻에서 영어 낱말 꺼내기`와 `낱말에서 짧은 글 읽기`의 별도 진입 카드는 통합했습니다. 옛 활동 ID/기록은 보존합니다.

보호자 설정에서 **파닉스 시작 단원**을 선택합니다. 1단원부터 반드시 다시 할 필요는 없습니다. 제공 교재 22개 단원을 원순서로 표시하며 `ai / ay`는 **앱 보충**으로 구별합니다.

작은 회차는 원문 단어 두 개를 순서대로 다룹니다. 각 단어에 대해 AI 음성 듣고 따라 읽기 → 먼저 듣지 않고 읽기 → 보고 철자 쓰기를 합니다. 이어 뜻만 보고 말하기, 안 보고 철자 쓰기, 교재 예문 읽기, 뜻 확인을 진행합니다. 완료 기록을 저장한 뒤 **다음 두 단어**, 단원 끝에서는 **다음 단원**으로 이어집니다. 최근 보호자 테스트 기록을 기반으로 단어 위치를 이어가며, 기록 요약 보관 범위는 기존 최근 40회입니다. 장기 복습 일정·개인별 숙달 자동 추천은 이번 범위에 포함하지 않습니다.

모델 듣기 단계는 음성을 자동 요청합니다. 독립 읽기·회상에서는 먼저 답을 들려주지 않으며 필요할 때 **AI 소리 듣기**를 누릅니다. 8개까지 현재 회차의 음성을 메모리에 보관하여 반복 호출을 줄입니다. 단원 페이지 번호와 교재/앱 보충 구분을 화면에 표시합니다.

### 쓰기와 평가의 범위
- 글자 버튼 또는 키보드로 철자를 실제 입력하고 확인합니다. 복사 단계는 정답이어도 독립 수행으로 집계하지 않습니다.
- 손글씨 연습판에서 손가락/펜/마우스로 따라 쓸 수 있습니다. 손글씨는 업로드·저장하지 않습니다.
- 손글씨 인식·획순 판정·자동 발음 채점은 없습니다. 읽기·말하기는 직접 관찰, 철자는 프로그램 비교입니다.
- AI 음성은 전체 단어/문장 모델입니다. 개별 음소의 정확성을 검증한 녹음 교재라고 주장하지 않습니다. 원문 STEP 1의 소리 결합 도표를 완전한 음소 음성 수업으로 옮긴 것은 아닙니다.
- 교재 예문에는 해당 회차 두 단어 외의 단어가 포함될 수 있습니다. 이때 AI 도움을 사용할 수 있고 도움 사용을 별도로 기록합니다.

## 서버·비용·보호
기존 `OPENAI_API_KEY`와 `LEARNING_COACH_ENABLED=guardian`을 재사용합니다. 선택 설정 `LEARNING_SPEECH_MODEL`의 기본은 `gpt-audio-1.5`입니다. 현재 공식 Audio 가이드에 있는 Chat Completions의 `modalities: [text,audio]` 및 WAV 출력 구조를 사용합니다. 읽어줄 텍스트와 제공자의 전사 텍스트 일치를 확인하지만 이는 실제 음질/발음의 검증을 대신하지 않습니다.

회화는 기존 텍스트 생성 뒤 유료 음성 생성 1회가 더 필요합니다. 기존 40턴/일·12턴/세션 예약을 공유하며 자동 유료 재시도는 없습니다. 교재 읽기는 별도 가족당 **120회/한국 날짜 하루** 예약을 먼저 처리합니다. 서버가 허용한 단원/항목 ID만 읽으며 임의 텍스트 낭독 API는 제공하지 않습니다. 예약 후 공급자 실패도 횟수에 포함될 수 있습니다.

음성/WAV/대화 전문은 가족 상태와 영수증·브라우저 저장소에 기록하지 않습니다. 키는 서버에만 있습니다. 외부 AI 제공자의 보관 정책까지 무보관으로 보장하지 않습니다. 아동 개인정보/음성 공개 조건은 별도이며 여전히 성인 보호자 테스트입니다.

## 배포 시 필요한 변경
1. 패치를 최신 저장소에 적용하고 `npm ci`, `npm run typecheck`, `npm test`, `npm run test:browser`를 실행합니다.
2. `family-action`에는 새 공유 학습 콘텐츠와 읽기 예약 액션이 필요합니다.
3. `learning-coach`에는 새 `narration.js`, `phonics-curriculum.ts` 및 해당 선언/의존 파일이 필요합니다. `good-learning-coach.ts` 배포 래퍼를 사용합니다.
4. 새 SQL 마이그레이션은 없습니다. JWT 확인과 기존 origin 설정을 유지합니다. 새로운 필수 API 키는 없습니다.
5. 서버 두 함수를 갱신하고 Pages 빌드를 배포한 뒤 실제 보호자 로그인으로 글→음성, 단어 낭독, 재생 차단 복구를 확인합니다. 상태 확인 버튼만으로 실제 모델 권한/음질을 확인한 것은 아닙니다.

이 문서는 v0.10 준비 당시의 기능 설계입니다. v0.11에서 운영 반영을 진행하며 최신 화면·관리 기능·배포 범위는 CHAT_LETTERS_V11.md와 해당 PR 기록을 확인합니다.
