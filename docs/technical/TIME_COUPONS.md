# 시간 쿠폰 사용법

## 기존 TV 이용권

이름에 `30분`, `1시간`, `1시간 30분`처럼 시간이 적힌 기존 보상과 쿠폰은 자동으로 시간 쿠폰으로 표시됩니다. 이미 사용 완료되거나 지급 취소된 쿠폰의 시간은 다시 생기지 않습니다.

이름에 시간이 없거나 자동 인식이 어려우면 보호자 **보상 → 수정 → 시간을 나눠 쓰는 쿠폰**을 켜고 **한 장의 기본 이용 시간 (분)**을 입력하세요. 이 설정은 이후 지급·교환·뽑기로 받는 쿠폰에 적용됩니다. 받은 쿠폰의 시간은 보상을 수정해도 바뀌지 않습니다. 시간형 체크를 끄면 한 번에 사용하는 일반 쿠폰으로 설정됩니다.

## 시간을 나눠 지급하기

1. 보호자 **보상 → 해당 보상의 직접 지급**을 누릅니다.
2. **한 장당 지급할 시간 (분)**과 **지급 개수**를 입력합니다. 빠른 선택 버튼도 사용할 수 있습니다.
3. 지급 사유와 확인 화면의 총 시간을 확인한 뒤 **선물 지급**을 누릅니다.

예를 들어 TV 30분 보상에서 10분, 2장을 선택하면 별 차감 없이 **10분짜리 쿠폰 2장**, 총 20분을 받습니다. 각 장의 시간은 1분부터 원래 보상의 시간까지 지정할 수 있습니다. 수량은 1~20장입니다. 유한 재고를 사용하는 보상은 시간이 짧아도 **쿠폰 한 장당 재고 1개**를 사용합니다.

상점에서 별로 교환하거나 뽑기로 받으면 한 장의 기본 시간이 지급됩니다.

## 필요한 시간만 사용하기

1. 연준이 **내 쿠폰 → 사용할 시간 선택**에서 이번에 쓸 분 수를 입력합니다.
2. 보호자 **쿠폰 → 승인 대기**에서 요청한 시간을 확인하고 승인합니다.
3. 실제 이용한 뒤 보호자 **제공 대기 → ○분 사용 완료**를 누릅니다.

30분 쿠폰에서 10분을 사용 완료하면 **20분이 남고 다시 사용 가능** 상태가 됩니다. 이후 5분을 쓰면 15분이 남습니다. 남은 시간까지 모두 쓰면 사용 완료로 표시됩니다.

사용 요청과 승인만으로는 시간이 줄지 않습니다. 아이가 요청을 취소하거나 보호자가 **다음에 사용**으로 돌려보내도 시간이 그대로 남습니다. 요청한 시간을 바꾸려면 요청을 취소한 뒤 새로 요청하세요.

## 기록과 기기 동기화

보관함의 각 쿠폰에서 **남은 시간**, **받은 시간**, **시간 사용 내역**을 확인할 수 있습니다. 사용 내역에는 사용한 분 수, 일시, 확인한 보호자가 남습니다. 한 번이라도 사용한 선물은 입력 오류용 지급 취소를 할 수 없습니다.

여러 기기의 사용 요청은 같은 가족 기록에 반영됩니다. 다른 기기에서 먼저 처리한 오래된 확인 화면은 새로고침 안내와 함께 거절되며, 같은 요청의 결과를 재확인해도 중복으로 지급·차감되지 않습니다.

시간은 **1~1,440분 사이의 정수**로 관리합니다. 자동 타이머나 TV 기기 제어 기능은 포함하지 않으며, 보호자가 실제 이용 후 완료를 기록합니다.
