# 구조·보안·운영 메모

## 구성

```text
src/ui.ts           순수 화면 렌더링, 사용자 문자열 HTML 이스케이프
src/main.ts         화면 전환·폼·확인창·요청 재시도·15초 조회
src/learning.ts     보호자 학습 테스트·공개 확인·짧은 활동 진행
src/backend.ts      체험 저장소 / Supabase 클라우드 어댑터
src/auth.ts         로그인·세션 갱신·HTTP 오류 구분·공개 설정 검사
src/export.ts       JSON 다운로드와 수식 주입 방지 CSV
supabase/functions/_shared/domain.ts  거래 규칙의 단일 원본
supabase/functions/_shared/service.ts 명령 검증·요청 영수증·revision 재시도
supabase/functions/_shared/learning.ts 학습 권한·초안/공개·완료/칭찬 규칙
supabase/functions/_shared/learning-content.ts 검토한 고정 활동과 완료 답 검증
supabase/functions/family-action/     실제 Edge HTTP 진입점 (웹 빌드 제외)
supabase/migrations/                 RLS·초대·원자적 상태 commit
scripts/build.mjs                    ES module 배포 + standalone HTML 생성
```

## 거래 경계

클라이언트는 action과 무작위 requestId만 보냅니다. 사용자 ID는 검증한 Auth 사용자에서 가져오고, 가족의 실제 역할은 매 명령마다 DB에서 조회합니다. 클라이언트가 지정한 잔액/당첨 결과/역할은 사용하지 않습니다.

서버는 현재 상태를 읽고 규칙을 적용한 후 `family_commit`에 예상 revision을 전달합니다. DB는 가족 행을 잠그고 역할과 revision을 재검증합니다. 변경 충돌 시 서버는 최대 4회 현재 상태로 다시 계산합니다. 뽑기 quote가 달라지면 사용자 재확인을 요구합니다.

같은 가족/요청 번호는 한 번만 적용합니다. 중복 요청의 입력 또는 지급자가 다르면 거절합니다. 동일 요청 재전송에는 이전 결과를 돌려줍니다. 원장 합계와 잔액이 일치하지 않거나 잔액이 음수이면 DB commit을 거절합니다. UI는 통신 오류나 인증 만료 시 요청 번호를 보존해서 기존 처리 여부를 재확인할 수 있게 합니다.

뽑기는 서버의 `crypto.getRandomValues`로 결정하고 결과를 저장한 뒤 화면에 표시합니다. 숨김·품절 보상을 제외한 현재 확률을 공개합니다. 서버 재시도 중 아직 commit되지 않은 난수는 바뀔 수 있지만 사용자에게 보이는 결과는 저장된 결과 한 개뿐입니다.

## 접근 권한

admin: 칭찬, 보상 설정, 교환/뽑기 대행, 승인/실사용, 가족 관리.  
giver: 칭찬 지급과 가족 기록 열람.  
child: 기록 열람, 확정 교환/뽑기, 쿠폰 요청/취소, 목표 변경.

DB의 RLS는 현재 사용자가 속한 가족 데이터만 읽도록 제한합니다. 브라우저 역할의 테이블 쓰기는 금지하고 승인된 RPC와 Edge 명령만 사용합니다. `family_commit`은 서버 역할 전용입니다.

초대 토큰은 랜덤 UUID 두 개를 연결한 64자리 문자열입니다. UUID의 고정 버전/variant 비트를 제외한 유효 무작위 비트 수는 약 244비트이며, '완전한 256비트 엔트로피'라고 주장하지 않습니다. DB에는 SHA-256 해시만 저장합니다. 사용/만료/취소된 초대는 거절하고 발행자가 더는 관리자가 아니면 사용할 수 없습니다. 가입과 해제는 가족 행 → 초대 행 순서로 잠급니다.

## UI·키·데이터 안전

사용자 작성 문구는 DOM 삽입 전에 이스케이프합니다. CSV의 수식 시작 문자는 중립화합니다. 배포 HTTP 헤더는 스크립트를 자체 출처로 제한하고 외부 iframe 삽입을 막는 방향으로 구성했습니다. 실제 배포 헤더 적용은 아직 확인하지 않았습니다.

브라우저에는 공개 키만 넣습니다. 서버 비밀 키는 Edge 환경에만 남습니다. 세션은 브라우저 localStorage에 저장되며 부모 기기 잠금·로그아웃이 필요합니다. 별도 PIN 잠금은 없고, 이 앱에 광고/분석/제3자 스크립트는 넣지 않았습니다.

PWA 워커는 정적 앱 셸만 캐시하고 인증/API 응답은 가로채지 않습니다. 오프라인 클라우드 거래를 큐에 넣어 나중에 몰래 실행하지 않습니다. PWA 설치는 서버 HTTPS 배포 이후 실제 기기에서 검증해야 합니다.

## 모델 선택과 한계

가족 한 행에 JSON 상태를 저장하는 소규모 MVP입니다. 한 번의 거래를 일관되게 다루기 쉽지만 조회마다 전체 가족 상태를 받으므로 기록이 커지면 비효율적입니다. 4 MB 제한을 두었고, 대규모/장기 공개 서비스로 확장하려면 테이블 분리와 페이지 조회로 바꿔야 합니다. 가족 1개당 아이 1명이며 한 인증 사용자도 1개 가족만 참여합니다.

부모가 동일 설정을 동시에 편집하면 보상은 version 검사로 막습니다. 뽑기 상자 설정은 마지막 저장이 적용되는 현재 구조이며 각 뽑기에는 최신 quote 확인을 요구합니다. 관리 설정 전반의 편집 충돌 UI는 후속 개선 대상입니다.

공개 서비스용 CAPTCHA, 요청 빈도 제한, 접근 로그 보존 정책, 강제 계정 복구/가족 소유권 이전, 실제 RLS 침투 테스트는 미완료입니다. 서비스 운영 완료나 외부 보안 감사를 받은 코드라고 표현하지 않습니다.

## 보호자 학습 테스트

학습은 선택적인 가족 상태로 추가하며 기존 가족에 자동 공개하지 않습니다. 공개 초안과 실제 공개 설정을 분리하고, 모든 공개/중지에 단조 증가하는 순번을 사용합니다. 완료는 기존 명령/CAS 경계를 거치고, 칭찬은 보호자의 별도 확인 이후 기존 원장에 기록합니다. 자세한 상태·기록 보관·배포 경계는 [학습 안내](LEARNING_LAB.md)를 참고하세요.
