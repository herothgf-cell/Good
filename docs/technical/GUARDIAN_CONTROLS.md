# 보호자 기능 사용 안내 — v0.3

## 이름 수정
보호자로 로그인 → 우리 가족 → 구성원 오른쪽 이름 수정 → 표시 이름 입력 → 이름 저장.
휴대폰에서는 하단 더보기 → 우리 가족. 계정 삭제나 재초대 불필요. 표시 이름은 1~30자이며, 이메일·비밀번호·역할은 변경하지 않는다. 이전 칭찬·지급 기록의 당시 이름은 보존한다. 다른 보호자가 먼저 이름을 바꾸면 새로고침 후 재수정해야 한다.

## 별 직접 지급
칭찬 붙여주기 → 별 직접 지급 → 지급할 별 개수와 사유 → 지급 내용 확인 → 별 지급.
기존 잔액에 더하는 기능이며, 잔액 덮어쓰기/벌점 기능이 아니다. 1~10,000개의 정수만 허용. 지급자·시간·사유는 별 기록에서 확인. 일반 칭찬 1~3개와 구분해 칭찬 횟수는 늘리지 않는다.

## 보상 직접 지급
보상 만들기 → 등록 선물 옆 직접 지급 → 사유 → 확인 → 선물 지급.
별을 차감하지 않고 아이 보관함에 쿠폰 1장을 넣는다. 유한 재고는 1개 줄어든다. 숨김/품절 보상은 지급할 수 없다. 지급된 쿠폰에는 보호자 선물, 지급자와 사유가 표시된다. 실제 사용은 기존처럼 사용 요청 → 승인 → 사용 완료.

## 안전장치
세 기능 모두 보호자 전용. 화면 버튼뿐 아니라 서버/DB에서 역할을 확인한다. 네트워크 오류 후 같은 요청 결과 확인은 같은 요청 번호를 재사용하므로 별이나 선물이 중복되지 않는다. 이미 성공한 작업을 새 요청으로 다시 지급하는 것은 별도 지급으로 처리되므로 확인창을 읽어야 한다.

초기 적립은 운영 요청을 받아 한 번만 처리한다. 앱을 열거나 새 가족을 만들 때 자동으로 13개씩 주는 기능은 아니다. 기존 가족 기록과 쿠폰을 초기화하지 않는다.
