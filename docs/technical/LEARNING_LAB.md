# 보호자 학습 테스트 — v0.7.0

기존 칭찬 별·선물·쿠폰 앱에 영어와 수학 활동을 추가했습니다. 기존 가족의 학습 공개 상태는 기본 **미공개**입니다. 앱을 업데이트하는 것만으로 아이 화면에 학습이 나타나지 않습니다.

## 보호자 사용 순서

1. 보호자 계정으로 로그인하고 **학습 테스트** 메뉴를 엽니다. 작은 화면의 아래 메뉴에서는 **학습**으로 표시합니다. 설정 화면에도 바로가기가 있습니다.
2. 활동의 **미리 해 보기**를 눌러 다섯 문항을 끝까지 진행합니다. 이 기록은 보호자 테스트이며 실제 별·쿠폰·아이의 일일 학습 횟수에 영향을 주지 않습니다.
3. 공개할 활동, 하루 횟수, 활동당 칭찬 별을 선택하고 **초안 저장**을 누릅니다. 기본 초안은 영어 색깔 + 수학 10 만들기, 하루 2회, 활동당 별 1개입니다. 하루 횟수는 1~4회, 별은 0~3개로 정할 수 있습니다.
4. 아이에게 보여 줄 준비가 되었을 때만 **아이에게 공개**를 누르고 별도의 확인 화면에서 확정합니다. 선택한 모든 활동을 현재 버전으로 테스트해야 공개할 수 있습니다.
5. 공개 후 아이가 활동을 마치면 보호자 화면의 학습 기록에서 확인합니다. 별을 설정한 활동은 보호자가 **칭찬 별 보내기**를 눌러야 기존 칭찬 편지와 별 원장에 반영됩니다. 도움을 받거나 다시 골랐다는 이유로 별을 줄이지 않습니다.

공개를 멈추려면 **공개 중지**에서 다시 확인합니다. 아이 기기는 기존 15초 갱신 또는 새로고침 때 메뉴와 진행 화면을 닫습니다. 서버는 공개 중지 즉시 새로운 완료 요청을 거절합니다. 이미 저장된 완료 기록과 칭찬은 보존됩니다.

## 처음 제공하는 활동

| 영역 | 활동 | 내용 |
|---|---|---|
| 영어 | 영어로 색깔 찾기 | 짧은 영어를 듣고 색깔 선택 |
| 영어 | 영어로 동물 찾기 | 친숙한 동물 이름과 그림 연결 |
| 영어 | 무엇을 달라고 할까요? | `A ball, please.` 같은 짧은 부탁 이해 |
| 수학 | 10을 채워요 | 열 칸 그림에서 10까지 필요한 수 찾기 |
| 수학 | 수의 집을 찾아요 | 100 묶음·10 묶음·낱개, 0이 있는 자리값 |
| 수학 | 그림 속 수 이야기 | 10 안의 덧셈·뺄셈과 0이 남는 상황 |

각 활동은 검토한 고정 문항 5개입니다. 짧은 한국어 안내, 큰 선택 버튼, 힌트, 함께 답 보기, 다시 선택하기, 쉬었다 가기를 제공합니다. 중간에 나가면 완료로 저장하지 않습니다. 매번 같은 문제이므로 반복 수행 결과를 새로운 수준 검사로 해석하지 않습니다.

## 영어 소리와 기기

영어 소리는 **소리 듣기**를 눌렀을 때 기기의 영어 음성을 사용합니다. 로컬 음성이 확인된 경우에만 재생하며, 음성이 없거나 아직 준비되지 않은 기기에서는 글자 도움 또는 보호자의 읽어 주기로 진행합니다. 다시 버튼을 누르면 최신 음성 목록으로 확인합니다. 영어를 말해 보는 것은 선택이며 발음 점수는 매기지 않습니다.

마이크를 열거나 음성을 녹음·업로드하지 않습니다. 외부 AI API를 호출하거나 결제형 AI 서비스를 새로 연결하지 않았습니다. 앱을 가리거나 다른 화면·역할로 이동하면 재생을 멈춥니다.

반응형 브라우저 화면은 휴대폰·태블릿 너비로 검사합니다. 실제 iPad Safari의 음성, OS 버전, 홈 화면 설치 동작은 해당 기기에서 확인해야 합니다. 우선 보호자 계정으로 영어 한 활동을 끝까지 진행하며 확인할 수 있습니다.

## 기록을 읽는 방법

완료 기록의 혼자/도움 수는 선택 시도와 사용한 도움을 구분한 활동 기록입니다. 영어 듣기 실력, 발음, 독해력, 지능 또는 웩슬러 지표를 측정한 점수가 아닙니다. 보호자가 읽어 주거나 아이가 추측한 경우까지 자동 판별하지 않습니다.

초기 활동을 너무 쉽거나 어려워하면 보호자가 선택 목록을 조정합니다. 자유 영어 대화, 자동 난이도 추정, 독해 과정, 웩슬러 하위 지표 훈련은 이번 버전에 포함하지 않았습니다. 이 기능들의 도입 여부는 실제 활동 반응을 확인한 뒤 별도로 결정합니다.

## 구현과 운영

- 기존 `State`에 선택적인 `learning` 필드를 추가합니다. 해당 필드가 없는 가족은 미공개 초안으로 읽습니다. DB 마이그레이션이나 운영 가족 상태 일괄 재작성은 필요하지 않습니다.
- `draft`와 `publication.settings`는 독립된 복사본입니다. 초안을 수정해도 공개 중인 활동과 별 조건이 바뀌지 않습니다.
- 초안 저장은 `draftVersion`을 검사합니다. 공개 확인은 초안 버전과 `publicationSequence`를 함께 검사합니다. 공개와 공개 중지 때 모두 순번을 올리므로 다른 보호자의 중지를 오래된 확인창이 덮어쓸 수 없습니다.
- 보호자만 테스트·설정·공개·중지·칭찬할 수 있습니다. 아이는 현재 공개 버전의 선택된 활동만 완료할 수 있습니다. `giver`에는 학습 관리 권한을 추가하지 않습니다. 역할은 기존 서버 회원 조회로 확인합니다.
- 클라이언트가 보낸 완료 답을 공통 모듈에서 검증합니다. 문항 ID 5개가 정확히 한 번씩 있어야 하고 최종 선택, 시도 횟수, 도움 종류를 확인합니다. 이 검증은 활동 데이터의 정합성을 확인하며 실제 사람의 학습 행동을 증명하지 않습니다.
- 요청 영수증과 별도의 학습 UUID를 모두 사용합니다. 같은 완료의 다른 요청 번호·다른 아이 기기 재전송은 요약을 중복 생성하지 않습니다. 보호자 두 명이 동시에 칭찬해도 하나의 칭찬·원장만 생성합니다.
- 아이 활동의 하루 제한은 가족 전체와 한국 날짜 기준입니다. 보호자 테스트는 이 제한에 포함하지 않습니다.
- 가족 상태에는 보호자 테스트 최신 30개, 아이 완료 최신 60개를 유지합니다. 보호자 화면에서 보관 중인 아이 기록 전체를 확인할 수 있습니다. 오래된 미확인 기록도 이 60개 범위를 넘으면 요약에서 빠지므로 장기 기록이 필요하면 별도 저장소로 확장해야 합니다.
- 칭찬에는 영구적인 `learningRunId` 참조가 남습니다. 요약이 보관 범위를 벗어나거나 칭찬을 오류 정정해도 같은 기록에 별을 다시 주지 않습니다.
- 기존 명령 영수증(`family_events`)에는 완료 때 제출한 문항/선택 ID, 시도 횟수, 도움 종류가 포함됩니다. 진행 중 화면, 음성, 매 클릭 시각은 저장하지 않습니다. 가족 상태 요약의 보관 제한과 명령 영수증의 보관은 별개입니다.
- 가족 데이터의 기존 접근 범위는 유지됩니다. 별도의 민감한 검사 보고서나 진단 정보는 저장하지 않습니다.

## 배포

웹 소스와 Edge 함수가 함께 업데이트되어야 합니다. 현재 `supabase/deploy/good-praise.ts`는 상대 경로의 서버 규칙을 사용하므로 다음 파일을 원래 경로를 유지해 한 번에 업로드합니다.

```text
supabase/deploy/good-praise.ts
supabase/deploy/deno.json
supabase/functions/_server/config.js
supabase/functions/_server/config.d.ts
supabase/functions/_shared/service.ts
supabase/functions/_shared/domain.ts
supabase/functions/_shared/learning.ts
supabase/functions/_shared/learning-content.ts
```

`verify_jwt: true`와 기존 Pages 출처 검증을 유지합니다. 새로운 Edge 규칙은 이전 웹 버전의 쿠폰 명령과도 호환되므로 Edge를 먼저 적용하고 검증된 웹을 배포할 수 있습니다. 배포 과정에서 실제 가족의 학습 공개나 칭찬 지급을 실행하지 않습니다.

검증 근거와 실제 릴리스 상태: [학습 테스트 검증 기록](../verification/LEARNING_LAB_RELEASE.md).
