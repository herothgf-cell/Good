# v0.11 통합 대화 · 행동 관리 · 칭찬 편지

## 영어 대화
보호자 → 학습 테스트 → AI 영어 회화에서 글과 마이크 입력을 같은 대화에 사용합니다. AI는 왼쪽, 보호자는 오른쪽 말풍선입니다. 보낸 글은 응답을 기다리는 동안 즉시 표시되고 실패하면 실패 표시와 함께 남습니다. 실패한 요청을 자동 재전송하거나 다음 AI 문맥에 넣지 않습니다.

AI 답변 본문과 모델 영어 표현을 화면에 표시하고 같은 내용을 생성 음성으로 재생합니다. 한국어 도움말은 보조 글입니다. 기기의 설치된 영어 음성에 의존하지 않습니다. 답변의 다시 듣기는 메모리에 있는 같은 음성을 재생하며 유료 재호출하지 않습니다. 브라우저가 소리를 차단하면 소리 재생 버튼을 사용합니다. 마이크는 짧게 녹음 후 보내는 방식이며 상시 통화가 아닙니다.

v0.10에서 준비한 파닉스 통합 과정도 포함합니다. 단원·단어 순서, 듣기·읽기·철자 입력·손글씨 연습·뜻 확인을 이어갑니다. 원본 PDF는 공개 저장소/웹 배포에 포함하지 않으며 docs/references의 출처·쪽수 대응표를 유지합니다. 개별 음소 정확도, 손글씨 인식, 자동 발음 채점은 구현 범위가 아닙니다.

## 행동 삭제와 순서
보호자 행동 관리의 ↑/↓ 버튼으로 순서를 바꿉니다. 전체 행동 화면은 저장 순서대로 표시하며 아이 홈의 대표 행동 우선 표시 규칙은 유지합니다. 삭제는 확인 후 목록에서 제거합니다. 내부 삭제 표식은 남고 이미 발급한 편지·별·쿠폰 기록은 삭제하지 않습니다. 같은 삭제 ID를 재사용해 과거 기록과 섞을 수 없습니다.

서버가 보호자 권한과 행동/목록 버전을 확인합니다. 다른 기기가 먼저 수정하면 최신 목록을 확인하도록 안내하며 오래된 순서로 덮어쓰지 않습니다. 삭제한 행동은 이전 화면이나 요청에서 다시 칭찬할 수 없습니다.

## 새 편지와 보관함
아이 홈의 큰 편지는 읽지 않은 유효한 편지만 표시합니다. 새 편지가 없으면 작은 안내와 보관함 링크만 보입니다. 새 편지함과 읽은 편지 보관함을 분리합니다. 편지를 열어 보기만 해서는 읽음 처리하지 않고 `읽었어요 · 보관하기` 버튼으로 이동합니다. 읽음/보관은 별을 추가 지급하지 않습니다. 입력 오류로 정정된 편지는 두 아이 편지함에서 제외되며 감사 기록은 유지됩니다.

## 칭찬일자
자유 칭찬 편지와 행동 칭찬 모두 오늘·어제·날짜 선택을 제공합니다. `praiseDate`는 칭찬한 행동의 날짜이고 `createdAt`은 실제 전송 시각입니다. 원장의 별 지급 시각은 오늘의 실제 처리 시각으로 유지합니다. 날짜는 한국 시간 기준이며 존재하지 않거나 미래인 날짜는 서버에서 거부합니다. 옛 편지는 기존 전송 시각의 한국 날짜로 표시합니다.

행동별 하루 횟수는 선택한 칭찬일자를 기준으로 검사합니다. 오늘 한도를 사용했더라도 어제 날짜를 선택할 수 있으나 어제 한도가 남아 있어야 합니다. 어제 일에 대한 편지를 오늘 보내면 새로 도착한 읽지 않은 편지로 표시됩니다.

## 배포와 설정
새 SQL 마이그레이션은 없습니다. `family-action`과 `learning-coach`를 이 버전의 같은 고정 커밋으로 배포한 뒤 웹을 배포합니다. 기존 `OPENAI_API_KEY` / `LEARNING_COACH_ENABLED=guardian`을 재사용합니다. 새 API 키 등록은 필요하지 않습니다. 기존 learning-realtime / learning-english 함수는 삭제하거나 변경하지 않습니다.

학습은 여전히 보호자 테스트 전용이고 학습 공개·보상 설정을 변경하지 않습니다. 운영 가족 데이터를 테스트용으로 수정하지 않습니다. 실제 사용자 계정의 AI 음질·계정 모델 권한과 실물 iPad 음성은 별도 확인입니다.
