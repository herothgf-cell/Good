# v0.5 사용 안내: 보호자 관리와 칭찬 편지

## 연준이
홈 첫 카드에서 새 칭찬 편지 개수, 보낸 사람, 칭찬 내용과 받은 별을 확인합니다. 편지를 열어 `읽었어요`를 누르면 읽음 상태가 가족 서버에 저장되고 다른 아이 기기에도 반영됩니다. 편지는 삭제되지 않습니다. 처음 도입할 때 과거 편지도 아직 읽음 기록이 없어 새 편지로 표시될 수 있습니다. 단순 별 직접 지급은 원장 기록이며 칭찬 편지가 아닙니다. 편지를 보내려면 일반 칭찬 또는 행동 칭찬을 사용하세요.

메뉴는 홈 / 별 받기 / 상점 / 뽑기 / 내 쿠폰입니다. 쿠폰 획득 이후 사용 요청 → 보호자 승인 → 실제 사용 완료 흐름을 유지합니다.

## 보호자
메뉴는 홈 / 별 주기 / 쿠폰 / 보상 / 설정입니다. 홈의 승인 대기·제공 대기에서 해당 쿠폰을 바로 확인합니다. 실제 상점 교환·뽑기·사용 요청은 보호자가 할 수 없으며 서버에서도 거부됩니다. 보상 직접 지급(1~20장)과 별 지급은 기존처럼 가능합니다.

- 설정 → 별 받는 행동 설정: 행동별 이름·설명·아이콘·1~3별·하루 1~10회·공개·홈 우선 표시를 편집합니다. 초기 예시를 바꾸거나 숨길 수 있습니다.
- 별 주기 → 약속한 행동 칭찬하기: 어른이 확인한 행동을 선택하여 설정된 별과 편지를 지급합니다. 횟수 제한은 같은 가족 전체와 한국 날짜 기준이며, 자유롭게 입력하는 일반 칭찬과는 별개입니다.
- 보상 → 뽑기 설정: 확률·비용·횟수를 저장합니다. 시험 뽑기는 현재 저장된 설정을 사용하며 실제 별·재고·쿠폰·일일 횟수를 바꾸지 않습니다.
- 보상 검색과 상태 필터를 사용하여 공개/숨김/품절 보상을 찾습니다. 아이 화면 미리보기에서는 실제 구매가 되지 않습니다.
- 쿠폰은 같은 종류와 상태끼리 묶어 보지만 각각 고유 번호를 유지하여 한 장씩 요청/승인/사용합니다.
- 설정 → 별·지급 기록: 잘못 직접 지급한 별은 사유를 남겨 한 번만 정정할 수 있습니다. 잔액이 부족하면 회수하지 않습니다.
- 직접 지급한 선물의 아직 사용 요청하지 않은 쿠폰만 입력 오류로 취소할 수 있습니다. 원본 쿠폰과 취소 사유는 남습니다. 새 버전에서 재고를 실제 차감한 쿠폰만 유한 재고를 복원합니다. 과거 쿠폰은 발급 당시 재고 정보가 없으므로 재고를 임의 복원하지 않습니다.

## 아이콘·모바일
아이콘 선택은 별도 팝업에서 전체/최근/디지털/놀이·외출/음식/운동/배움/특별 분류로 제공합니다. Esc 또는 닫기는 아이콘 창만 닫고 입력 중인 편집 내용을 유지합니다. 편집창 자체를 닫을 때 변경이 있으면 확인합니다.

편지 본문은 홈 20px, 상세 모바일 21px, 상세 PC 22px입니다. 주요 관리 본문은 15~18px, 입력칸은 16px, 주요 터치 버튼은 44~50px입니다. 실제 브라우저 및 사용자 확대 설정에 따라 물리적 크기는 다릅니다.

기존 가족 JSON의 선택 필드만 확장했습니다. 별·쿠폰·계정 초기화나 새로운 유료 리소스 생성이 필요하지 않습니다. 폰 운영체제 푸시, PC 잠금/자동 로그인, 다자녀별 독립 지갑은 이 버전에 포함하지 않습니다.

## 검증 범위
새 역할별 기능/화면 검증은 `tests/experience_browser_test.py`가 담당합니다. 옛 browser_test.py와 guardian_browser_test.py는 보호자 구매와 이전 메뉴를 전제로 하므로 실행 스크립트에서 대체했으며 원본 파일은 보존했습니다. Chromium의 저장소 예시로 검증하며, 실제 iOS/Android 기기나 실제 사용자 비밀번호로 로그인한 운영 거래 검증을 대신하지 않습니다. 200% 루트 글꼴 검사는 실제 브라우저 확대 인증이 아닙니다.
