# 보호자 학습 테스트 v0.8

기존 칭찬 별·쿠폰 앱 안의 **보호자 → 학습 테스트**에서 사용합니다. 이번 새 학습은 보호자만 시험하며, 연준이 화면으로 공개하는 기능은 넣지 않았습니다. 테스트를 마쳐도 별이나 쿠폰이 지급되지 않습니다. EBS 연결은 후속 작업입니다.

## 무엇이 달라졌나요?

| 활동 | 시험할 내용 |
| --- | --- |
| 영어 회화 | 놀이·가게·블록 만들기 상황에서 짧은 표현을 말하기. 실제 AI 연결 시험과 고정 시나리오를 구분합니다. |
| 단어 회상 | 뜻과 모델을 확인한 다음 영어 글자를 가리고 떠올려 말합니다. |
| 영어 읽기 | 기본 ai/ay. 모델 단어 → 스스로 읽기 → 같은 패턴의 새 단어 → 짧은 문장 → 의미 확인. CVC와 silent-e도 선택할 수 있습니다. |
| 두 자리 계산 | 덧셈과 뺄셈을 직접 입력합니다. 받아올림·받아내림을 각각 조절합니다. |
| 돈에서 다른 표현으로 | 100원 동전·1,000원·10,000원 지폐에서 같은 수량을 묶음과 식으로 연결한 뒤 새 수량을 적용합니다. |
| 시계와 시간 | 시각 읽기 이후의 시간 이동. 같은 시 안, 시를 넘기기, 시작 시각·걸린 시간까지 조절합니다. |
| 달력과 날짜 | 며칠 뒤 날짜를 구합니다. 같은 달과 다음 달로 넘어가는 상황을 나눕니다. |
| 같은 수씩 묶기 | 2개씩·3개씩 묶음 → 반복 덧셈 → 곱셈 표현 → 새로운 묶음 상황. |
| 규칙과 빈칸 | 한 가지 변화 또는 두 가지 변화를 번갈아 적용합니다. |

문제를 다시 시작하면 검수된 범위 안에서 수나 낱말이 달라집니다. 기본 수학 계산은 두 자리 수이며, 큰 금액을 계산했다는 이유로 모든 계산을 고난도로 바꾸지 않습니다. 익숙한 표현을 다른 표현으로 옮길 수 있는지 별도로 시험합니다.

## 보호자가 먼저 확인할 순서

1. 보호자로 로그인한 뒤 **학습 테스트**를 엽니다. 상단에 **보호자 전용 · 아이 미공개** 표시를 확인합니다.
2. **영역별 다음 활동 설정**에서 다음 활동의 조건을 고르고 저장합니다. 영어는 ai/ay, 수학은 두 자리 계산의 혼합 조건을 기본으로 시작합니다.
3. 먼저 **두 자리 덧셈과 뺄셈**, **돈에서 그림과 식으로**, **낱말에서 짧은 글 읽기**를 시험합니다. 숫자 입력칸과 화면 키패드를 모두 사용할 수 있습니다.
4. 필요한 경우 힌트·풀이·모델을 선택합니다. 도움을 사용하거나 다시 시도한 결과는 ‘스스로’와 구분합니다. 막힌 단계는 ‘다시 연습’으로 마무리할 수 있습니다.
5. 말하기·읽기는 보호자 또는 본인의 관찰임을 표시합니다. 기기 음성을 들었다는 사실로 발음이나 읽기 성공을 판정하지 않습니다.
6. 활동 끝의 저장 상태를 확인합니다. 저장 실패 시 **같은 기록 다시 저장**을 사용하면 같은 요청 번호로 확인합니다. 다른 기기에서 설정이 바뀌면 새 설정으로 다시 시작합니다.

기록은 **보호자 테스트 진도**입니다. 아이의 실제 실력 점수나 진단 결과가 아닙니다. 최근 40회 요약과 영역별 누적 관찰을 보관하며, 칭찬 원장·쿠폰·기존 아이 학습 기록은 별도로 유지합니다. 진행 중에 나가면 아직 완료하지 않은 답은 보관하지 않습니다.

이전 v0.7 학습 관리와 기록은 화면 하단의 이전 학습 메뉴에서 계속 확인할 수 있습니다. 이전 공개 설정의 동작을 보존했으며, 새 v0.8 활동은 그 공개 선택에 포함되지 않습니다.

## 실제 AI 대화 연결

**영어 회화 → 보호자 목소리로 AI 연결 테스트**에서 먼저 연결 상태를 확인합니다. 이 영역은 고정 시나리오와 별개의 실제 서버 대화입니다. 체험판은 실제 AI에 접속하지 않습니다.

가족 공유 보호자의 음성을 최대 15초 녹음하거나, 짧은 문장을 글로 보냅니다. 서버가 음성을 글로 바꾸고 짧은 영어 응답·필요한 한국어 힌트·모델 표현을 만듭니다. 영어 답변은 기기에 설치된 로컬 영어 음성으로 읽습니다. 사용할 수 있는 음성이 없거나 재생이 막히면 답변을 글로 표시합니다. 기기 음성은 영어 철자 하나씩의 파닉스 소리 평가에 사용하지 않습니다.

기본 서버 모델은 `gpt-transcribe`와 `gpt-4.1-mini`입니다. `/audio/speech` 모델은 공식 문서상 2027-01-06 종료 예정이므로 신규 의존성으로 추가하지 않았습니다. 모델 가용성과 계정 권한은 실제 연결 시 별도로 확인해야 합니다.

Supabase 프로젝트의 **Edge Functions → Secrets**에 다음 값이 필요합니다. 브라우저 설정·GitHub 소스·대화창에 비밀 키를 넣지 않습니다.

| 서버 설정 | 값 |
| --- | --- |
| `OPENAI_API_KEY` | API 프로젝트의 비밀 키 |
| `LEARNING_COACH_ENABLED` | `guardian` |
| `LEARNING_COACH_CHAT_MODEL` | 선택 사항. 기본 `gpt-4.1-mini` |
| `LEARNING_COACH_TRANSCRIBE_MODEL` | 선택 사항. 기본 `gpt-transcribe` |

키와 활성화 값이 없으면 준비 중으로 표시합니다. `learning-coach` 함수를 JWT 확인을 켜서 배포해야 하며, `family-action`도 v0.8 공유 모듈을 함께 배포해야 새 테스트 기록을 저장할 수 있습니다. SQL 마이그레이션은 추가하지 않았습니다.

서버는 로그인과 실제 가족의 보호자 역할을 검사합니다. 가족별 한국 날짜 하루 40턴, 세션당 12턴·15분으로 제한합니다. 유료 요청을 보내기 전에 사용량을 예약하며, 실패하거나 결과가 불확실한 턴은 자동으로 다시 보내지 않습니다. 예약이 소비된 실패도 횟수에 포함될 수 있습니다.

앱은 음성 파일이나 실제 AI 대화 전문을 가족 기록·브라우저 저장소에 보관하지 않습니다. 대화는 현재 화면의 메모리에만 남고, 화면 이탈·일시 정지·기기 숨김·역할 변경 때 지웁니다. **AI 공급자의 처리·보관 정책까지 ‘보관 없음’이라고 보장하는 것은 아닙니다.** `store:false`도 ZDR 승인을 대신하지 않습니다. 이 릴리스에서는 성인 보호자의 목소리로만 시험하며 아이 음성 공개는 별도 조건 검토 후 진행합니다.

## 배포·검증 범위

- 기존 기능을 포함한 TypeScript/Edge 타입 검사와 Node 회귀 검사.
- 실제 DOM에서 입력·힌트·오답·모델·관찰·저장 재시도·권한 변경·오래된 설정을 확인하는 브라우저 검사.
- 보호자 기본 메뉴와 보존된 이전 메뉴, 390px 휴대폰 및 1024px 태블릿 화면 확인.
- 실제 컨트롤러를 사용한 녹음 종료, 녹음 중 화면 숨김, 최종 오디오 조각 전송, 재생 전 마이크 종료, 과대 녹음 차단 검사. 미디어·공급자 경계는 테스트 대역입니다.
- AI 서버 권한·크기·할당량·동시 중복 요청·오류 응답 검사. 실제 API 계정과 실제 iPad 마이크를 사용한 대화 품질 검증은 별도입니다.
