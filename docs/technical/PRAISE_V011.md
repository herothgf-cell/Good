# v0.11 — 칭찬 행동·편지 관리와 통합 영어

## 보호자
- **설정 → 별 받는 행동 설정**: 위/아래 이동 버튼으로 즉시 순서 저장. 삭제는 확인 후 목록에서 제외하며 이전 편지·별·쿠폰은 유지합니다. 숨긴 행동도 관리 순서에 포함됩니다. 홈에서는 기존 `우선 표시` 그룹을 유지하고 그룹 내에서 저장 순서를 따릅니다.
- **별 주기**: 일반 칭찬과 행동 바로 칭찬 모두 `칭찬일자 · 행동한 날`을 선택합니다. 기본 오늘, 오늘/어제 버튼, 달력 입력. 실제 존재하는 과거 또는 오늘 날짜만 허용합니다.
- `praiseDate`는 행동한 날, `createdAt`은 실제 보낸 시각입니다. 별은 전송 시점에 지급되고 과거 원장을 수정하지 않습니다. 행동별 하루 횟수는 선택한 칭찬일자로 계산합니다. 구기록은 보낸 시각의 한국 날짜로 표시합니다.
- 작성 중 수동/자동 갱신이나 전송 실패가 발생해도 같은 보호자의 편지 내용·날짜는 유지합니다. 다른 계정으로 전환하면 공유하지 않습니다. 성공한 전송만 작성란을 비웁니다.

## 아이
- 홈의 큰 편지는 **안 읽은 편지 중 최근 도착한 편지**만 표시합니다. 모두 읽으면 본문을 재노출하지 않고 간결한 안내만 표시합니다.
- 새 편지함은 안 읽은 편지만, **칭찬 편지 보관함**은 읽은 편지만 보여 줍니다. 보관함은 작은 목록으로 표시하고 눌러서 원문을 읽을 수 있습니다.
- 열어보기만으로 읽음 처리하지 않습니다. `읽었어요 · 보관함으로`를 눌러야 이동합니다. 읽음은 기존 가족 상태에서 기기 간 공유합니다. 읽거나 다시 읽어도 별을 추가 지급하지 않습니다.

## 통합 영어 (이전 v0.10 파일 수정본 포함)
- 이전 운영 v0.9에는 글·음성 통합 수정본이 배포되지 않았습니다. 이번 소스는 그 수정본을 포함합니다.
- 보호자 **학습 테스트 → AI 영어 회화** 한 화면에서 글/마이크 입력, AI의 글 답변과 AI 생성 음성, 다시 듣기·음성만 멈추기를 사용합니다. 별도 실시간 음성 화면은 기본 경로에서 제거했습니다.
- **파닉스 · 듣고 읽고 쓰기** 한 메뉴: 소리 듣기 → 읽기 → 보고 쓰기 → 뜻에서 떠올리기 → 안 보고 쓰기 → 문장·복습. 기기 설치 음성 대신 서버의 AI 생성 음성을 사용합니다.
- 손글씨 연습판은 연습용이며 자동 손글씨/획순/발음 평가는 아닙니다. 전체 단어와 문장을 읽습니다.
- PDF 원본은 공개 저장소/배포물에 넣지 않습니다. 교재 대응표와 인용 출처만 소스에 있습니다.
- 계속 보호자 테스트 전용·별 0개이며 아이 공개 설정을 자동 변경하지 않습니다. EBS 연동은 포함하지 않습니다.

## 운영 반영
- `family-action` 및 `learning-coach` Edge 함수를 동일한 소스 커밋으로 배포한 뒤 Pages를 배포합니다. `learning-realtime`/기타 함수는 변경하지 않습니다.
- 기존 `OPENAI_API_KEY`, `LEARNING_COACH_ENABLED=guardian`를 재사용합니다. 추가 비밀 키는 없습니다. 음성 모델 기본값은 `gpt-audio-1.5`이며 계정의 모델 권한·잔액은 실제 사용 시 확인해야 합니다.
- 앱 하단과 service worker shell 버전: **v0.11.0**. 예전 화면이면 새로고침 후 앱/탭을 닫았다가 다시 엽니다. 사이트 데이터 삭제나 가족 연결 초기화는 필요하지 않습니다.
- DB 마이그레이션/운영 가족 데이터 초기화/자동 보상/공개 설정 변경을 하지 않습니다.

## 보안·검증
- 행동 삭제/순서 변경은 서버에서 보호자 권한과 버전을 검사합니다. 삭제된 ID는 과거 기록용으로 남겨 오래된 수정 요청이 복원하지 못하게 합니다.
- 순서 변경은 현재 ID 전체를 중복 없이 보내야 합니다. 동시 수정·삭제와 충돌하면 최신 목록에서 다시 시도하도록 합니다.
- 실제 서버 권한, 유료 예약/멱등성, 응답 크기, 음성·대화의 비저장 원칙을 유지합니다.
- 로컬 자동·브라우저 검사와 실제 기기의 유료 API 음질 검증은 별개입니다. 실제 iPad/사용자 계정의 대화 품질을 대신 검증했다고 주장하지 않습니다.
