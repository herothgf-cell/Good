## 작성자 자체 검토 (독립 리뷰어 없음)
사용자 요청과 diff를 별도 패스로 비교했습니다. 쿠폰/별 원장과 수학 문항 생성은 변경하지 않았고 아이 공개 액션도 추가하지 않았습니다. 보안은 서버의 실제 가족 멤버 역할 확인 후 호출, 정확한 읽기 ID 목록, 사전 유료 예약, 재전송 멱등성 구조를 재사용했습니다. 대화/오디오를 family state나 localStorage에 저장하지 않습니다.

발견 후 실패 테스트로 재현해 보완한 사항:
1. 기존 `apiTransient`의 20KB 텍스트 상한이 WAV 응답을 거부했습니다. 오디오 coach 경로만 최대 3.1MB 스트림 상한으로 변경했고, 실시간 SDP 경로는 20KB를 유지했습니다. 무한/과대 스트림은 취소하며 재시도하지 않습니다.
2. 전체 22단원의 세부 기록과 기존 기록을 함께 쓰면 200개 항목 한도를 넘었습니다. 서버가 만드는 고정 기술 ID의 한도를 400개로 조정하고 전체 단원 수행 테스트로 확인했습니다.
3. 다음 단원 설정 저장 중 화면을 나가면 늦게 새 수업을 여는 경합이 있었습니다. 같은 세션·가족·보호자 신원이 유지될 때만 다음 단원과 음성을 시작하도록 막았습니다.
4. 기존 기기 음성 lifecycle 테스트를 AI 오디오 lifecycle로 전환했습니다. 이전 오디오의 늦은 종료/오류가 다음 오디오와 타이머를 바꾸지 않는 8가지 경우를 보존했습니다.

## 결정과 남은 한계
- AI 텍스트를 먼저 확정한 후 동일 내용을 AI 음성으로 생성합니다. 사용자 요청의 동일 글/음성 일치를 우선하며, 음성 생성 지연과 API 비용이 추가됩니다. 자동 유료 재시도는 없습니다.
- PDF는 원본을 별도 보관하고 앱에는 출처가 있는 22단원의 단어/예문 일부만 사용합니다. 앱 UI/한국어 뜻/관찰/두 단어 회차는 앱의 각색입니다. ai/ay는 보충임을 명시합니다.
- 음소별 발음 모델, 음성 채점, 손글씨 인식·획순 평가, 장기 간격 반복 알고리즘은 구현하지 않았습니다. 전체 단어/문장 낭독과 철자 비교, 손글씨 연습으로 범위를 표시합니다.
- 원문 예문의 난도가 해당 회차 두 단어보다 높을 수 있어 AI 도움과 별도 관찰을 허용합니다. 강제 만점이나 별 지급은 없습니다.
- 시작 단원 선택은 보호자 설정입니다. 기존 대화 도움 설정은 이전 수준 조정 값으로 남지만 실제 AI 모델의 발화 품질은 실제 계정에서 확인해야 합니다.
- 자기 검토는 독립 코드 리뷰보다 약합니다. 실제 배포 전 패키지의 인수인계 지침에 따라 최신 main 차이와 서버 의존 파일을 재확인해야 합니다.
