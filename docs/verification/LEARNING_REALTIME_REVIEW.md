## 자체 검토에서 보완한 사항

- JSONB 영수증 키 순서가 바뀌어도 같은 재시도임을 인정: 실패→수정→통과.
- 원격 오디오를 받지 못한 상태에서 마이크를 열지 않음: 실패→수정→통과.
- 서버 종료 확인 실패를 숨기지 않음: 실패→수정→통과.
- 종료가 앞서 처리된 뒤 만들어진 call의 정리 실패도 call ID를 보존: 실패→수정→통과.
- 보호자 활성화를 끄면 다음 heartbeat에서 종료: 실패→수정→통과.
- 종료 기록을 줄일 때 살아 있는 call을 삭제하지 않음: 실패→수정→통과.
- 자막/타이머 갱신으로 입력 포커스를 잃거나 전체 앱을 다시 만드는 문제를 피함: 브라우저 재현→부분 갱신→통과.
