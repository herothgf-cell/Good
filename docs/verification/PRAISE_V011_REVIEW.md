## 자체 검토에서 확인·수정한 사항
- 저장했던 v0.10 패치에 shell 버전과 새 음성/파닉스 모듈 목록이 빠져 있었음. v0.11 캐시와 완전한 모듈 목록으로 수정하고 새 회귀 테스트로 확인.
- 편지/날짜가 갱신·전송 실패에 유실되지 않도록 같은 보호자의 작성 폼을 보존. 성공한 전송만 초기화.
- 행동 삭제 확인, 현재 버전 검증, 삭제 이후 오래된 수정·지급 거절. 목록 순서와 동시 변경 충돌 테스트.
- 안 읽은/읽은 편지를 분리하고 100개 제한으로 오래된 편지가 사라지지 않도록 전체 목록을 보존. 읽은 정정 편지도 기록으로 보관.
- 과거 칭찬일자로 횟수를 계산해도 실제 별 원장·전송 시각은 현재 시각을 유지. 유효하지 않은 날짜·미래 날짜 거절.
- 아이의 학습 공개/기존 원장/시간 쿠폰 사용 정책을 바꾸지 않음. 운영 테스트 거래를 만들지 않음.

## 결정 및 한계
- 삭제는 기록 보존을 위한 소프트 삭제이며 복구 메뉴는 추가하지 않음. 새로운 행동은 새 ID로 등록 가능.
- 순서 조정은 접근성이 좋은 위/아래 버튼을 사용. 기존 홈 우선 표시 그룹은 유지.
- 회화는 같은 답변의 텍스트를 먼저 확정한 뒤 AI 음성을 생성하는 턴제. 낭독 API 처리 시간이 추가되며 재생 차단 시 수동 재생 버튼 표시.
- 음성 생성 실패는 글을 유지하고 실패를 명시. 검증되지 않은 발음/인지 점수는 제공하지 않음.
- 이전 realtime 실험 코드와 독립 서버 reaper 한계는 그대로 남지만 기본 UI에는 노출하지 않음.
- PDF 원문/개인정보/비밀 키를 새 공개 커밋에 포함하지 않음.
